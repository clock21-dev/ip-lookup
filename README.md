# 🌐 IAAM21 X TOCLOCK.ID - IP Lookup

## 🚀 About

**IAAM21 X TOCLOCK.ID - IP Lookup** adalah website pencarian informasi alamat IP dengan tampilan modern, dark-red cyber style, dan sistem lookup cepat.

Website ini dapat menampilkan informasi seperti:

- 🌍 Country / Negara
- 🏙️ City / Kota
- 📍 Region
- 🌐 IP Address
- 🛰️ Latitude & Longitude
- 🕒 Timezone
- 🏢 ASN / Provider
- 📡 Organization ISP

## ✨ Features

✔️ Dark Red UI Design  
✔️ Fast IP Lookup  
✔️ Responsive Mobile Design  
✔️ Auto Detect Your IP  
✔️ Custom Branding IAAM21 X TOCLOCK.ID  
✔️ GitHub & Cloudflare Ready

## ⚡ Installation

Clone repository:

```bash
git clone https://github.com/clock21-dev/ip-lookup.git
```

Masuk folder project:

```bash
cd ip-lookup
```

Lalu buka:

```txt
index.html
```

Atau gunakan **Live Server** di VS Code.
